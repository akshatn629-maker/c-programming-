# C Programming Practice Repository

This repository is a personal collection of beginner-friendly C programs created while learning the fundamentals of the C programming language. It covers basic syntax, arithmetic operations, conditionals, loops, grade calculations, swapping values, and simple problem-solving exercises.

The project is meant to help build a strong foundation in C and serve as a reference for learning and practice.

## Repository Overview

- Language: C
- Compiler: GCC / MinGW
- Editor: VS Code
- Purpose: Learning and practicing core programming concepts

## Getting Started

### Prerequisites

Install a C compiler such as:

- GCC on Linux/macOS
- MinGW or TDM-GCC on Windows

### Compile and Run a Program

Open a terminal in the project directory and run:

```bash
gcc my-c-programs/hello.c -o hello
./hello
```

On Windows with MinGW:

```bash
gcc my-c-programs/hello.c -o hello.exe
hello.exe
```

### Example: Run a program from the folder

```bash
gcc my-c-programs/sumeven.c -o sumeven
./sumeven
```
